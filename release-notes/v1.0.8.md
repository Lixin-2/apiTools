### 新功能

- 新增「更新中心」：独立面板，分「apiTools」与「更新日志」两页，不再检查后一闪而过
- 启动后自动静默检查更新，之后每 6 小时复查一次；发现新版本时顶栏图标出现红点提醒
- 更新日志按版本列出历史记录，可展开查看更新说明，并提供跳转到对应发布页的入口

### 改进

- 顶栏工具图标重新分组：主题、检查更新、GitHub 依次排列，语义更清晰
- 压测按钮与发送、保存按钮统一为 36px 高，视觉上对齐
- 版本列表优先读取随安装包发布的清单文件，网络受限时自动切换到订阅源，避免加载失败

### 问题修复

- 修复更新日志一直转圈加载不出的问题（失败后会自动重试形成死循环）
- 修复点击检查更新时加载图标抖动的问题
- 修复从 GitHub 下载的安装包被 macOS 判定为「已损坏」的问题（打包时补全签名）
- 修复 Windows 平台缺失更新清单导致无法在线更新的问题
- 移除顶栏与更新日志中无实际作用的刷新按钮
